# PdfCraft 0.9.0 for AROS — test 4

For AROS x86_64 ABIv11 (such as AROS One). Experimental and not optimised; the window is drawn by the CPU.

## Changes since test 2

- Fixed a crash after closing PdfCraft when it was started from Workbench. On exit the program could release its starting drawer twice, which could damage memory and make the desktop crash or freeze afterwards.
- The archive now has a Workbench icon with the stack PdfCraft needs, and unpacks into a drawer named `PdfCraft`.

## Installation

Unpack the archive into a drawer, for example `UnZip PdfCraft-0.9.0-test4.x86_64-aros-v11.zip -d Work:`, and double-click the PdfCraft icon. From a Shell, run `Stack 4000000` before starting `PdfCraft`. PdfCraft is also available as `pdfcraft` in the apkg catalogue.

## Known limitations

- Text recognition (OCR), printing, signing, and pictures or files through the clipboard are not available.
- Very large, encrypted or damaged PDF files may not open.
- This is not a binary for AROS mainline (ABIv1).

The source archive contains the build recipe and AROS patches used for this build.
