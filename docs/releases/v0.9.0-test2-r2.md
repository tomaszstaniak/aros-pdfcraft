# PdfCraft 0.9.0 for AROS — test 2 (rebuild 2)

For AROS x86_64 ABIv11. Experimental and not optimised; CPU rendering only.

## What is included

- The PdfCraft window (view, search, zoom, rotate pages, save) and `pdfcraft-cli` (information, text, rendering pages to PNG).
- Opening files with the standard AROS file requester.

## Installation

Unpack the archive into a writable drawer, `CD` to it and run `Protect PdfCraft +e` and `Protect pdfcraft-cli +e`, then start `PdfCraft` from a Shell. There is no Workbench icon.

## Known problem

A desktop crash or freeze after closing PdfCraft has been reported, including when no document was opened. The cause remains unresolved. `README.txt` in the archive explains how to record a log.

## Known limitations

- Text recognition (OCR), printing, signing and pictures through the clipboard are not available.
- Very large, encrypted or damaged PDF files may not open.
